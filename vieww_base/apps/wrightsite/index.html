Wright

Describe the outcome. Agents set up the project, build it, check it, and keep it understandable.

Wright turns a person's intent into a working, repeatable project. You describe what should exist; it drafts a typed blueprint, shows you — in plain words generated from that blueprint, never by a model — what will run, what each step may touch, what it may cost and how done is checked; and only after you approve does a workforce of agents build it inside a sandbox, test it, have it reviewed, and deliver it. Change one requirement later and only the affected work runs again.

Built-in models, no key needed · a Landlock sandbox · durable runs with receipts · cron schedules in your own time zone · secrets kept in the OS keychain.
