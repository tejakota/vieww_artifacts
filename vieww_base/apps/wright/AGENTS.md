# AGENTS.md — instructions for agents (and humans) working on Wright

This file is the project memory for any agent contributing to this repo.
Read it before touching anything. It exists so that a sleepy engineer at
3AM — or an agent with no context — can navigate this codebase and do the
right thing.

## What this project is

Wright turns intent into a working, repeatable project. The blueprint (a
typed, versioned file — the UI edits it, people may too) is the source of
truth; the compiler turns it into stages of project agents plus injected
system agents; the engine fires it behind a permission gate and a kernel
sandbox; the event spine records everything durably for resume and replay.

## Non-negotiable rules

1. **One dependency.** The workspace's only external dependency is the
   vieww repository (`tejakota/vieww_artifacts`) at ONE pinned commit, and
   only the `app` crate's `ui` feature uses it (crates `vieww` +
   `vieww-platform-winit`; ADR-011). The headless build has zero external
   crates. If your change needs a crate, build the capability in-house
   (mimicking a proven design, cited in the PR) or argue for an exception
   in a new ADR. `wright-core` stays std-only, always.
2. **Unsafe only where the OS must be called**: `runtime/src/tls.rs` (the
   OpenSSL FFI) and `tools/src/sandbox.rs` (Landlock, namespaces,
   `pre_exec`). Every block carries a `// SAFETY:` comment. The executor
   has zero unsafe; keep it that way.
3. **No crypto, ever, by hand.** TLS reaches the OS backend. Hashing ports
   the public-domain BLAKE3 reference (pinned to official vectors). Any
   signature scheme (recipes, SSO) goes through OS APIs per ADR-012.
4. **Secrets are references.** `keychain:` scheme only, anywhere a secret
   appears — blueprints AND `config.kdl`. A secret value in code, logs,
   events, or a test is a bug you fix before the PR is reviewable.
5. **Permissions are provenance.** The permission set is part of the task
   cache key (`permission_change_invalidates_provenance` will find you).
6. **Fresh means fresh.** Tasks that read the outside world (volatile) or
   touch it (delivery) are never served from the cache, and delivery is
   never retried. Keep `Reads` / `Effect` in `core/src/palette.rs` honest.
7. **Nothing leaves the machine before the checks.** Delivery tasks depend
   on the Reviewer; a rejection or a test failure skips them. A cached
   approval never outlives a new test failure.
8. **The model never describes permissions.** The Confirm Gate summary is
   generated by `core/src/confirm.rs` from the typed blueprint.
9. **The event spine is append-only and fsynced** before the action it
   describes counts as done. Resume reads it; replay projects it; nothing
   rewrites it.
10. **Guardrails never invalidate work.** Budgets/schedules are not in
    cache keys or refire plans (tests in `core/src/blueprint/diff.rs`).
11. **Prompts are contracts.** Templates live in `agents/src/lib.rs`, are
    versioned (`PROMPT_VERSION`, part of every cache key), and are
    reviewed like code.
12. **Tests are not optional.** New behavior ships with tests. Bug fixes
    ship with the test that would have caught them.

## Conventions

- Rust 2021, MSRV **1.89** (vieww's floor). `cargo test --workspace` and
  `cargo clippy --workspace --all-targets --features wright/ui` must pass
  with zero warnings.
- Errors the user can see are plain-language sentences that say what to
  do next ("run `wright secret set keychain:wright/anthropic`").
- CLI output is ASCII, no color — it gets piped and pasted.
- Validation rejects; the compiler assumes valid input (and re-checks
  cycles anyway).
- The KDL dialect: one positional argument per node; newline-separated
  statements; decimals lex as text. Grammar: top of
  `core/src/blueprint/parse.rs`.
- Wright's own state lives OUTSIDE projects (`~/.wright/projects/…`), so
  a sandboxed agent can never touch it (ADR-013).

## Where things are

| Task | File |
|---|---|
| Add a blueprint field | `core/src/blueprint/model.rs` + `parse.rs` + `canon.rs` + `diff.rs` (invalidation rule!) + `confirm.rs` (how it is described) + tests |
| Add a tool | `core/src/palette.rs` (spec: caps, `Reads`, `Effect`, schema) + `tools/src/lib.rs` (impl, takes a `Permit`) + tests |
| Add a system agent | `core/src/compiler/mod.rs` (SystemKind + placement) + `agents/src/lib.rs` (contract) + `engine/src/mock.rs` (script) |
| Add a provider | `runtime/src/models.rs` (build + stream decoder, canned-byte tests) + `runtime/src/config.rs` (built-in entry) |
| Change firing behavior | `engine/src/firing.rs` — then run `cargo test -p wright-engine` (end-to-end, ~1 min) |
| Change the project skeleton | `core/src/convention.rs` + `docs/PROJECT-CONVENTION.md`; `engine/tests/skeletons.rs` runs every language's tests |
| Change a UI screen | `app/src/ui.rs`; check with `wright ui <project> --snapshot <dir>` and look at the PNGs |
| Touch the executor | `runtime/src/executor.rs` — read the whole file first; keep zero unsafe; keep cancellation cooperative |
