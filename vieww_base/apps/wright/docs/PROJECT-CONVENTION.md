# The Universal Project Convention

*The seed idea was: "replace the hurdle of project setup — folder
structure, logging, testing — using agents." This document is the part
of that setup that should not need an agent at all.*

Every project Wright creates has the same shape, in every language. The
skeleton is laid by **Shipwright**, a built-in step that is deterministic
code (`core/src/convention.rs`): no model, no tokens, milliseconds,
byte-identical every time. Agents then work *inside* a structure they did
not have to invent, which is what makes their output navigable by other
agents, by other harnesses (Claude Code, Codex, Kimi Code, dsh), and by a
sleepy engineer at 3AM.

## The shape

```
<project>/
  blueprint.kdl      the source of truth
  README.md          what this is; how to run and test it; the agents; the layout
  AGENTS.md          the rules, for agents and humans working ON the project
  .gitignore
  artifacts/         what agents read and write (`in` / `out`), by exact name
  logs/              structured JSON-lines logs, one file per component (git-ignored)
  src/ | bin/        code
  tests/ | test/     tests — runnable with the language's standard toolchain only
  .github/workflows/ci.yml   (when the `ci` chip is on)
```

Wright's own state (run logs, cache, receipts) lives outside the project,
in `~/.wright/projects/` — `wright where` prints the path.

## Per language

| Language | Code | Log helper | Tests | Test command (default) | Run command (default) |
|---|---|---|---|---|---|
| python | `src/<slug>/` package with `__main__.py` | `src/<slug>/log.py` | `tests/test_*.py` (unittest) | `PYTHONPATH=src python3 -m unittest discover -s tests -t . -q` | `PYTHONPATH=src python3 -m <slug>` |
| node | `src/index.js` (ES modules) | `src/log.js` | `test/*.test.js` (node:test) | `node --test` | `node src/index.js` |
| rust | `src/main.rs` | `src/log.rs` | `tests/*.rs` | `cargo test --quiet` | `cargo run --quiet` |
| shell | `bin/main.sh` | `lib/log.sh` | `tests/test_*.sh` + `tests/run.sh` | `sh tests/run.sh` | `sh bin/main.sh` |
| none | — | — | — | — | — |

`<slug>` is the project name made package-safe: "HN Daily Digest" →
`hn_daily_digest`.

## Rules

1. **Zero-install tests.** The generated test command uses only the
   language's standard toolchain — no pip, no npm install, no crates. A
   fresh machine runs the tests the moment the skeleton lands. This is
   enforced by `engine/tests/skeletons.rs`, which lays every language's
   skeleton and runs its test AND run commands. (That test caught a real
   bug during v0.2: a Rust string continuation had eaten the indentation
   of the Python logger.)
2. **One log format.** JSON lines with at least `level`, `component`,
   `event`; Python and Node add `ts`. `WRIGHT_LOG_DIR` redirects the
   directory (tests use it).
3. **Never overwrite.** Shipwright writes a file only if it does not
   exist; re-running a firing is idempotent and edits — by agents or
   humans — are never clobbered.
4. **Artifacts by exact name.** `in` / `out` names are plain file names
   (letters, digits, `- _ .`); they are paths under `artifacts/` and are
   validated as such.
5. **Git from the start.** Shipwright runs `git init` if the folder is not
   a repository yet. It never commits for you; agents may, through the
   sandboxed `git` tool, as `Wright (<agent>)`.

## Changing the convention

Edit `core/src/convention.rs` (templates are raw strings at column 0 so
the generated bytes are exactly what you read), update this document, and
run `cargo test -p wright-engine --test skeletons`. Changing the skeleton
of an existing project's language refires every agent of that project.
