- `film_lab/keynote_z/` — **THE SPARK — THE viewwstudio release film, the sixth build, and the single film folder (the earlier builds — keynote v1–v5, THE DISTANCE product_film, the studio_film cut — were retired at the consolidation; their deterministic sources remain under `vieww_base/examples/film_lab/src/`).** A 3:41 · 1080p60 · 24-scene film in four kishōtenketsu acts, every frame rendered by vieww's own headless rasterizer (`FrameDriver` + `NativeRenderer`, raw RGBA streamed into ffmpeg, nothing added in post). **Act III mounts the actual viewwstudio app** — the real `Shell`, the real `Studio` state, the real element runtime, the real `rustc` pipeline — driven by a frame-indexed script through the real input pipeline: the film types and the studio's editor types, the film taps and the demo navigates, the film presses Render and `rustc` runs. **And the score is the framework's too** — every note synthesised by `vieww-audio` (`Tone`/`Mixer`, `Biquad`, `Delay`, `Compressor`, `write_wav`), cut to the film's own timeline cue by cue (the break's crack, the wordmark letters landing, the crate pops, the alive keystroke, the tap, the compiles, the package landing, the ledger's stamp, the end card), muxed with `-c:v copy` so the picture's bytes are untouched. Rendering the score found and fixed a real `vieww-audio` bug: `Mixer::render` walked every tone to the mix's end — quadratic work for linear sound — and `tone_at` under-measured a duration when an attack outlasts its hold; both are fixed with tests. Ships with the MP4 (h264 + AAC 192k stereo), 24 per-scene contact sheets, the census manifest, and the tap-calibration receipts from `kzcal`'s hit-tests against the real tree. Source: `vieww_base/examples/film_lab/src/keynote_z/` (render: `kzcal`, then `censusz`, then `masterz`; the score alone: `scorez <mp4>`).
