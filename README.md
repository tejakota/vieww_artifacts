# vieww_artifacts

Artifacts for the vieww repository.

- `film_lab/` — the element experiments: 8 rendered plates with source, contact sheets, metrics receipts, and the premium-UI reference run.
- `vieww_base/` — the vieww framework source itself (the full Rust workspace: 36 crates, examples, docs, CI). **All updates to vieww land here.** The `todo-upgrades.md` items are fixed in this tree — each entry's status and the change that resolved it are annotated in place.
- `todo-upgrades.md` — the bench's upgrade notes, annotated with resolutions.
