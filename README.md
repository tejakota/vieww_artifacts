# vieww_artifacts

Artifacts for the vieww repository.

- `film_lab/` — the element experiments: **44 rendered plates** (rounds 2–7) with source, a loopable `anim.gif` motion receipt per plate, contact sheets, metrics receipts, the pixel-probe evidence plate, and the premium-UI reference run. Round 6 was the berserk spectrum — the shape-count record (`galaxy`, 60,527 shapes/frame in 101 ms), the rect ceiling (`mandel`, 57,602/frame in 69 ms), the 4K master receipt (`hero4k`), glyph-run storms, procedural recursion, a hashed night city, a lensed black hole, a 4D tesseract, and the three genesis arcs (line → 3D avatar, text → blurred fade-away, drop → entire ocean). **Round 7 is the deep axes — the dimensions nobody had measured: the script axis (`han`, CJK through the shaper at 107 glyph runs/frame), the single-path axis (`megapath`, one 40k-segment line), the endurance axis (`longplay`, 256 frames with a flat kernel-RSS series), the simulation axis (`swarm`, 2,400 boids with the build/raster split receipted), the blend-mode matrix (`blendmatrix`, 16/16 modes distinct, non-separable faithful), compositor depth (`filterstack`, nested filters + σ sweep), the blur economy at 30-of-32 on the U-06 guard (`shadowplay`), and animated 256-stop gradients (`prism`) — which found U-23, the silent 8-stop truncation, on its first day.**
- `vieww_base/` — the vieww framework source itself (the full Rust workspace: 36 crates, examples, docs, CI). **All updates to vieww land here.** The `todo-upgrades.md` items are fixed in this tree — each entry's status and the change that resolved it are annotated in place. Round 5 landed `guard_filtered_layers_below` (U-06), `SceneReport::open_subpath_fills` + `Path::open_subpaths` (U-20's counter), and the full-turn `Path::arc` closing (U-22 — the census's first catch).
- `todo-upgrades.md` — the bench's upgrade notes, annotated with resolutions. U-01 through U-22; the remaining OPEN item (U-18, the hairline policy) now carries the probe plate's measured rung-ink ladder.
